# Third-party audio notices

All files below are included as local game assets. The Unity game plays locally decoded PCM copies of the CC0 audio assets.
No network request is made while the game is running.

## Music — OpenGameArt CC0 loop collection

All five files are supplied as explicit loops by their authors and are decoded locally for native playback.

- `city-loop.mp3` — [City Loop](https://opengameart.org/content/city-loop-0), by wipics, CC0.
- `technological-messup.mp3` — [Technological Messup](https://opengameart.org/content/technological-messup), by Centurion_of_war, CC0.
- `zenostar.mp3` — [ZenoStar](https://opengameart.org/content/zenostar), by Centurion_of_war, CC0.
- `revelation.mp3` — [Revelation](https://opengameart.org/content/revelation-0), by Centurion_of_war, CC0.
- `electronic-loop.mp3` — [Loop](https://opengameart.org/content/loop), by symphony, CC0.
