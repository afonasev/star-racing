Windows 01

Скачайте установщик Star Racing с GitHub и запустите его. Выберите папку установки: по умолчанию — Program Files\Star Racing. На последнем экране вместе находятся галочки создания ярлыка на рабочем столе и запуска игры. Обе включены по умолчанию; любую можно снять. Для установки потребуется подтверждение прав администратора. Если SmartScreen покажет предупреждение, проверьте адрес скачивания; для этого тестового выпуска выберите «Подробнее» → «Выполнить в любом случае».

Windows 10/11, 64-bit. Проверка установки и обновления на Windows пока ожидается.

macOS 02

Откройте .pkg и установите игру. Для обновления без запроса пароля рекомендуем папку Applications в вашем профиле. Для Mac с Apple Silicon и Intel, macOS 12 или новее.

Этот тестовый выпуск не нотариализован Apple. Если macOS заблокирует запуск, после проверки адреса скачивания откройте «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть».

Как обновлять игру 03

В главном меню откройте «Обновления». Игра покажет новую версию, описание и размер. Нажмите «Обновить», дождитесь загрузки, затем — «Перезапустить» либо закройте игру и запустите её снова.

Скачивание начинается только после нажатия «Обновить». Готовый пакет применяется после выхода: по кнопке «Перезапустить» или при следующем запуске. Настройки сохраняются. Если обновление недоступно, можно продолжать играть в установленную версию офлайн.

Как играть вдвоём 04

Игрок 1: WASD, Space — занос, Shift — нитро. Игрок 2: стрелки, Right Alt — занос, Right Shift — нитро.

Геймпад: RT/RB — газ, A — тормоз, LT/LB — занос, B — нитро. Базовый проверенный состав — 8 участников; большие составы пока требуют больше ресурсов.
